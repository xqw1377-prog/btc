--- test_boot_reconcile_detects_drift ---

    def test_boot_reconcile_detects_drift(self):
        # Pre-seed an open in the fake exchange but a flat ledger
        self.port.set_position_state("LONG", Decimal("0.1"), Decimal("100000.00"))
        boot = self.executor.boot()
        self.assertFalse(boot["ok"])
        self.assertEqual(boot["state"], PositionState.UNKNOWN.value)
        self.assertIn("exchange open, ledger flat", boot["reason"])

Contract: at boot, if the exchange reports an open position while the ledger
is flat, the system must detect drift and enter UNKNOWN — it must NOT be
silently treated as flat.
Disposition: REQUIRED_UNCOVERED — the reference Reconciler is NOT-BUILT and
the current kernel recover() only iterates persisted intents (no intent →
nothing is checked). Registered as gap BOOT-DRIFT, linked to G0 follow-up.
